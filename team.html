📥 Import Results · Redcell API + Proxy · AKTIV v13

Primær løsning er nå Redcell API. Den kan hente én skytter på nummer, eller hente resultater for alle skyttere som finnes i valgt target match. ESS/bookmarklet beholdes som fallback. Importen oppdaterer bare shooter.stages og endrer aldri lagtilhørighet.

Redcell API-import

Bruk denne for EHC-resultater fra ipsc.redcell.se. Den henter strukturert JSON direkte fra Redcell og matcher mot skyttere i valgt match på skytternummer/ehcNum.

CORS blokkerer direkte henting fra ipsc.redcell.se. Bruk Cloudflare Worker-proxy her. Worker-koden må være oppdatert til v13 kombinert ESS/Redcell-proxy.
API som brukes: /api/public/p/{slug}/shooter/{nr} og /api/public/p/{slug}/shooters.
Dette skal være selve ESS-resultatsiden/result-compare-lenken.
Dette skal være Cloudflare Worker-adressen, ikke ESS-lenken.

ESS Extractor Bookmarklet

Bruk denne når Cloudflare/automatisk henting bare får ECM Members Portal. Åpne ESS-resultatsiden i nettleseren der du er innlogget, kjør bookmarklet, og lim JSON/tekst inn i feltet under.

Tips: Lag et nytt bokmerke i nettleseren, kall det “ESS Extractor”, og lim hele koden over inn som URL/adresse.

Manual fallback

Bruk dette hvis automatisk henting feiler. Kopier tekst fra ESS/verify/results-siden og lim inn under.
